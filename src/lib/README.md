# lib — Utility Functions & Data Layer

Các hàm tiện ích và kết nối dữ liệu:

| File/Folder | Mô tả |
|-------------|-------|
| `utils.ts` | Helper functions chung (format price, date, slug...) |
| `constants.ts` | Hằng số toàn cục (navigation links, categories...) |
| `api/` | API client functions — gọi backend/CMS |
| `db/` | Kết nối database (nếu dùng trực tiếp) |
| `validations/` | Zod schemas cho form validation |
