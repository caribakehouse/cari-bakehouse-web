# components/ui — UI Components dùng chung

Các component primitive tái sử dụng trên toàn site:

| File | Mô tả |
|------|-------|
| `Button.tsx` | Button với các variant: primary, secondary, outline, ghost |
| `Card.tsx` | Card container cho sản phẩm, bài viết... |
| `Input.tsx` | Text input, textarea với label và error state |
| `Badge.tsx` | Badge/tag nhỏ (mới, bán chạy, hết hàng...) |
| `Modal.tsx` | Dialog/modal overlay |
| `Spinner.tsx` | Loading spinner |

> Tất cả component nên support `className` prop để override style.
