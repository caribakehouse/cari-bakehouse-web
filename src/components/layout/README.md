# components/layout — Layout Components

Các component cấu trúc layout của site:

| File | Mô tả |
|------|-------|
| `Header.tsx` | Thanh navigation chính — logo, menu, giỏ hàng, tìm kiếm |
| `Footer.tsx` | Footer — thông tin liên hệ, mạng xã hội, links |
| `Navigation.tsx` | Menu điều hướng (desktop + mobile responsive) |
| `MobileMenu.tsx` | Drawer menu cho mobile |
